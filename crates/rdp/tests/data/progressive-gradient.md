Synthetic 64x64 BGRA gradient: B=3*x, G=3*y, R=2*(x+y), alpha=255. RGB was encoded with the independent librfxencode shipped in Ubuntu xrdp 0.9.24, RLGR1/software mode. Its tile was wrapped in independently constructed MS-RDPEGFX SIMPLE/frame/region headers, with default scalar quantization and the original DWT boundary mode. No external RDP code is linked to the client. The fixture contains no captured user or server data.

The reduced-boundary pair uses the independent librfxcodec devel software PRO1 encoder. Planes: Y=64+((13*x+7*y+x*y)%96), Cb=128+trunc((x-32)/2), Cr=128+trunc((y-32)/2), scalar quantizers all 6. The second frame increases Y by 4 on the same encoder context and is emitted as a DIFFERENCE tile. It verifies reduced boundaries, color conversion and retained coefficient history.
